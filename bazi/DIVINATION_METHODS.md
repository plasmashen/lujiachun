# 命理占卜方法全景盘点

> 调研时间：2026-11-13
> 目标：把市面上在用的命理/占卜方法按「热度、原理、App 化程度、变现能力」四个维度排清楚
> 数据标注：★★★ 高可信（权威调查/审计）｜★★ 中（创始人/媒体）｜★ 低（第三方估算）

---

## 一、热度排名（唯一有权威调查数据的排序）

### 1.1 中国：后浪研究所《2025 年轻人玄学消费报告》

样本 668 份，女性 77.5%。**这是目前唯一公开可引用的中文细分数据。**

| 排名 | 方法 | 关注度 |
|---|---|---|
| 1 | **八字命理** | **60.0%** |
| 2 | **星座（西洋占星）** | **44.8%** |
| 3 | **塔罗牌** | **38.9%** |
| — | 东方玄学整体（易经/生肖/紫微斗数） | 20.7% |
| — | 西方占星术整体 | 34.0% |

**消费动机**（这个比排名更重要）：
- 缓解压力和焦虑 **70%**
- 寻求解释 **45.3%**

**年龄趋势**：年龄越大越信；00 后、95 后关注度高，且更需要「应急方案」。

> ★★ 信心中等：样本 668 份偏小，且是自我选择样本（关注玄学的人才会填）。但方向可信——**八字在中国的认知度确实远超塔罗**。

### 1.2 美国：Pew Research Center（2024 秋调查，2025-05 发布）

| 指标 | 数值 |
|---|---|
| 一年内至少咨询一次占星/塔罗/算命师 | **30%** |
| 主要为「图个乐」而非求指导 | 绝大多数 |
| 据其做重大人生决策 | 极少数 |
| 2024 跨国调查中「会看运势」的美国人 | 9% |

> ★★★ 高可信。权威机构、大样本、方法透明。
> **关键洞察**：30% 的人在用，但几乎没人真拿它做决定。**这是个娱乐品类，不是决策工具。** 这直接决定了产品该怎么做——卖体验，不卖准确性。

### 1.3 韩国：Trend Monitor

| 指标 | 数值 |
|---|---|
| 20 多岁对四柱/塔罗感兴趣 | **68.0%** |
| 30 多岁 | **67.5%** |

> ★★ 中。韩国四柱渗透率是全球最高的，这解释了 Jeomsin 1700 万下载（人口 5100 万）。

### 1.4 一个反直觉的对照

中国：**八字（60%）> 星座（44.8%）> 塔罗（38.9%）**
美国：占星/塔罗/算命师合计 30%，且塔罗与占星并列

**结论**：中文市场的主导方法是八字，不是塔罗。做塔罗是进入一个更小、更年轻、更饱和的池子；做八字是进入一个更大但更传统的池子。

## 二、东方命理体系

### 2.1 八字（四柱命理）—— 中文市场第一

| 维度 | 说明 |
|---|---|
| **原理** | 出生年月日时 → 四组干支（年月日时四柱，共 8 字）→ 五行生克 + 十神 + 神煞 |
| **输入** | 出生日期、时辰、性别（必需）；出生地（算真太阳时，可选） |
| **输出** | 四柱、大运（10 年一步）、流年、流月、流日、神煞、格局、旺衰 |
| **强项** | **人生结构与运势起伏**——事业节奏、财运周期、六亲关系 |
| **弱项** | 抽象，术语门槛高；不给具体事件，只给倾向 |
| **App 化程度** | **极高**——排盘算法完全可确定性实现（你已复刻到 100%） |
| **变现** | 付费详批 ¥9.9-39.9、会员订阅、真人咨询 |
| **代表** | 问真（74 万下载）、灵机、陈抟版、知易、天乙 |
| **热度** | 中国 60.0%（第一） |

**为什么适合 App**：输入只有三四个字段，输出是确定的符号系统，完全可以代码化。这也是你复刻问真能做到 100% 的原因。

### 2.2 紫微斗数 —— 台港第一，内地第二梯队

| 维度 | 说明 |
|---|---|
| **原理** | 出生年月日时 → 十二宫命盘（命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、事业、田宅、福德、父母）→ 安十四主星 + 辅星 + 四化 |
| **输入** | 同八字（日期、时辰、性别） |
| **输出** | 十二宫 + 星曜分布 + 四化飞星 + 大限流年 |
| **强项** | **具体面向**——哪个宫有问题一眼看得出（夫妻宫空 → 婚姻话题），比八字直观得多 |
| **弱项** | 流派分歧大（三合派 vs 四化派，看盘逻辑差别很大）；星曜多，学习曲线陡 |
| **App 化程度** | **高**——排盘确定性，但四化飞星流派多，实现要选一路 |
| **变现** | 一次性买断（紫微斗數排盤 $23.99，15 年老 App）、付费批命 |
| **代表** | 紫微斗數排盤（Ring）、紫薇斗数（180 万安装 / 11.9 万 MAU / 月收入 <$10K ★）、灵机紫微 |
| **热度** | 台港极高；内地含在「东方玄学 20.7%」内 |

**八字 vs 紫微的关键差异**（一句话）：
- **八字读「势」**：五行强弱 → 什么时候起、什么时候落
- **紫微读「面」**：十二宫 → 哪个领域出问题

所以做产品时：八字适合做「运势时间轴」，紫微适合做「人生领域雷达图」。

### 2.3 六爻 / 梅花易数 —— 问具体事件

| 维度 | 说明 |
|---|---|
| **原理** | 起卦（摇钱/时间/数字）→ 六爻卦象 → 世应、六亲、六神、动爻变爻 |
| **强项** | **具体单一事件的吉凶**——这笔生意成不成、这个人在不在、什么时候有消息 |
| **弱项** | 一事一测，不能看一生；时效短（通常几个月内） |
| **App 化程度** | **中高**——起卦可自动化，但解卦高度依赖经验 |
| **变现** | 按次付费咨询为主 |
| **代表** | 天乙（六爻模块）、问问塔罗（含六爻） |

### 2.4 奇门遁甲 —— 时机与策略

| 维度 | 说明 |
| --- | --- |
| **原理** | 时间 + 方位 → 九宫盘 → 八门、九星、八神、三奇六仪 |
| **强项** | **择时择向**——什么时候做、往哪个方向、谈判怎么谈、项目怎么推 |
| **弱项** | 极复杂，学习门槛所有术数里最高；起局方式多样（时家/日家/月家/年家） |
| **App 化程度** | **中**——排盘可做，但解读极难标准化 |
| **变现** | 高客单咨询（单次几百到几千）、企业顾问 |
| **代表** | 玄易（奇门模块）、FateMaster、测天机 |

### 2.5 其他东方体系（小众但有付费场景）

| 方法 | 用途 | App 化 |
|---|---|---|
| **梅花易数** | 随手起卦，快速断事 | 中 |
| **大六壬** | 事占，古代「三式」之一 | 低 |
| **太乙神数** | 国运/大势，几乎无人问个人 | 极低 |
| **铁板神数** | 号称能算出六亲生肖，验证感极强 | 低（多为江湖秘传） |
| **邵子神数** | 同上 | 极低 |
| **七政四余** | 中国古占星（日月五星+四余） | 中（问天AI 有做） |
| **姓名学** | 五格剖象、笔画吉凶 | **高**（纯查表） |
| **择日/黄历** | 婚丧嫁娶开业搬家 | **极高**（纯查表，需求刚性） |
| **风水（阳宅）** | 住宅朝向、格局 | 中（需户型图输入） |

**注意「择日/黄历」这一项**：它是最被低估的品类——需求刚性（结婚、开业、搬家都要）、算法确定（纯查表）、合规风险最低（不涉及预测个人命运）。农历类 App 常年霸榜就是这个原因。

### 2.6 相术（手相/面相/痣相）

| 维度 | 说明 |
|---|---|
| **原理** | 掌纹（生命线/智慧线/感情线/事业线）、面部十二宫、痣的位置 |
| **App 化程度** | **高，且是 2024-2026 最热的方向**——拍照 + CV 识别 |
| **强项** | **交互极轻**（拍张照就行，无需输入生辰）；视觉冲击强，适合短视频传播 |
| **弱项** | 准确性无法验证；2023 年央视曝光「上传狗照片也能算命」重创过整个赛道 |
| **变现** | 付费报告、导流咨询 |
| **代表** | 面相大师（20 万张人脸 108 个定位点训练）、Palmia、AI手相、FatePalm |
| **风险** | 人脸数据涉及生物识别信息，合规红线最高 |

**为什么相术在短视频时代爆发**：不需要用户输入任何数据（降低门槛）+ 结果可视化（适合截图分享）+ 一句话就能说清（适合 15 秒视频）。

## 三、西方命理体系

### 3.1 西洋占星（Astrology）—— 欧美第一

| 维度 | 说明 |
|---|---|
| **原理** | 出生时刻的天体位置 → 本命盘（12 宫 + 10 行星 + 12 星座 + 相位） |
| **核心概念** | 太阳星座（性格）、月亮星座（情感）、上升星座（外在形象）、宫位（人生领域）、相位（行星互动） |
| **输入** | **出生日期 + 精确到分钟的出生时间 + 出生地经纬度**（时间误差 4 分钟就可能换上升星座） |
| **变体** | 本命盘（Natal）、行运盘（Transit，预测）、合盘（Synastry，双人）、太阳回归（Solar Return，年度）、推运（Progressions） |
| **强项** | **性格与心理**——擅长讲「你是什么样的人」，比东方命理更心理化 |
| **弱项** | 预测具体事件能力弱；依赖精确出生时间 |
| **App 化程度** | **极高**——Swiss Ephemeris 是事实标准，开源可用 |
| **变现** | 订阅制（$9-15/月）为主 |
| **代表** | Co-Star（MAU 490 万）、The Pattern、Nebula、CHANI、Sanctuary |
| **热度** | 美国 30%（含塔罗/算命师）；中国 44.8% 关注星座 |

**中文市场的特殊性**：中国的「星座」几乎只等于**太阳星座**（12 种），跟真正的西洋占星（本命盘）差得很远。所以中文星座 App 做的是内容生意（每日运势），不是命盘生意。

### 3.2 塔罗牌（Tarot）—— 全球最普及的占卜形式

| 维度 | 说明 |
|---|---|
| **原理** | 78 张牌（22 大阿卡纳 + 56 小阿卡纳），按牌阵抽取，结合正逆位解读 |
| **牌阵** | 单张（每日）、三张（过去/现在/未来）、凯尔特十字（10 张，深度分析） |
| **强项** | **具体问题的当下指引**——「我该不该换工作」这类二选一问题；**门槛最低**（不需要生辰） |
| **弱项** | 时效短（通常 3-6 个月）；同一问题反复抽会矛盾 |
| **App 化程度** | **极高**——抽牌随机数即可，图库现成，解读文案可预写 |
| **变现** | 真人塔罗师按分钟（$1-5/min）、AI 抽牌、订阅 |
| **代表** | Purple Garden、Nebula、问问塔罗、Tarotlit |
| **热度** | 中国 38.9%（第三）；欧美与占星并列 |

**为什么塔罗是新人最容易做的品类**：
1. 不需要出生时间（最大的门槛消失了）
2. 牌义是公开的、固定的（78 张，文案可预制）
3. 抽牌 = 随机数（实现最简单）
4. 视觉好看（天然适合分享）

**但也是最饱和的**。塔罗 App 数量远超八字 App，且几乎没有技术壁垒。

### 3.3 数字命理（Numerology）

| 维度 | 说明 |
|---|---|
| **原理** | 生日/姓名 → 数字 → 生命灵数（Life Path）、表达数、灵魂数等 |
| **强项** | 门槛极低（只要生日或姓名），概念简单易传播 |
| **App 化程度** | **极高**（纯算术） |
| **变现** | 订阅、报告 |
| **代表** | Nebula（含数字学）、Numerology Life Path、Decoz |
| **热度** | 欧美中等，常作为占星 App 的附加模块 |

### 3.4 卢恩符文（Runes）

北欧 24 符文，抽取解读。小众，但客单价不低（实体符文石 + 课程）。App 化程度低，多作为塔罗 App 的附属功能。

### 3.5 其他西方形式

| 方法 | 说明 | App 化 |
|---|---|---|
| **咖啡占卜（Tasseography）** | 看咖啡渣图案，土耳其/希腊传统 | **中高**（2026 年出现多个 AI 拍照识别产品：Fenjan AI、FalorAI） |
| **水晶/能量** | 不是占卜，是消费（实体商品） | 电商为主 |
| **通灵/灵媒** | 真人服务 | 平台化（Keen、Kasamba） |
| **手相（西式）** | 掌纹解读 | 高（同东方相术） |

**咖啡占卜值得注意**：2026 年冒出一批「拍咖啡杯照片 → AI 识别图案 → 生成解读」的产品。这验证了一个模式：**任何「有视觉载体的传统占卜」都能被 CV + AI 重做成 App。**

## 四、印度体系（独立一大类）

### 4.1 吠陀占星（Jyotish）

| 维度 | 说明 |
|---|---|
| **原理** | 与西洋占星同源但用**恒星黄道**（Sidereal），不是回归黄道；核心是 27 宿（Nakshatra）+ 九曜（Navagraha）+ 大运（Dasha） |
| **差异** | 西洋占星重**性格与心理**；印度占星重**具体事件与时间点**（哪一年会发生什么） |
| **分支** | Siddhanta（天文）、Samhita（世运）、Hora（个人命理） |
| **核心工具** | Kundli（命盘）、Dasha（大运系统）、Panchang（历书） |
| **App 化程度** | **极高**——AstroSage 8000 万下载证明 |
| **变现** | 真人咨询按分钟（AstroTalk 模式）、免费工具 + AI |
| **代表** | AstroTalk（独角兽）、AstroSage（8000 万下载）、AstroSure |

**为什么印度能做成全球最赚钱的市场**：
1. Jyotish 是**主流文化**，不是亚文化（婚配、择日、取名都用）
2. 人工成本低，能供养 1 万+ 占星师
3. 英语市场可直接出口（AstroTalk 国际收入占 1/3）

### 4.2 其他印度方法

- **Vastu Shastra**（印度风水）：建筑朝向，B 端属性强
- **手相/面相**：同东方
- **宝石建议**：AstroTalk Store 卖宝石，年入 1.1 亿 RMB——**这是「占卜结果 → 实体商品」最成功的案例**

## 五、日韩体系

### 5.1 韩国四柱（사주）

本质是**中国八字的韩国本土化**，但做了三件事：
1. 语言与术语本土化（사주 = 四柱）
2. **内容量碾压**——Jeomsin 免费提供 700 万字运势内容
3. **真人咨询 + 首次免费 3 分钟**

| 项 | 数据 |
|---|---|
| Jeomsin 下载 | 1700 万+（人口 5100 万）★★ |
| MAU | 96.7 万 |
| 2026-08 韩国 AI 算命 App 月销售额 | 破 10 亿韩元 |
| MAU 前 10 命理 App 中已加 AI 的 | 6 个 |

**2026 年创新方向**：AI 把四柱结果画成 **Webtoon 漫画**（命理可视化）。

### 5.2 日本

| 特点 | 说明 |
|---|---|
| **主导形态** | **电话占卜**（1 分钟 180 円起），不是 App 内自助 |
| **市场规模** | 占卜服务 997 亿円（2023 年度，矢野）★★★ |
| **用户结构** | 90% 女性，80% 是 30-50 岁，**85% 问恋爱** |
| **热门方法** | 四柱推命、星座、塔罗、手相、血型性格 |
| **App 生态** | 四柱推命有独立小生态（フォーステラー等）；手相 App 竞争激烈 |
| **代表公司** | ヴェルニ（电话占い）、カリス、SATORI、恋愛相談 METHOD |

**日本最值得学的一点**：把占卜做成**服务业**（真人电话），而不是软件。用户买的是一段被倾听的时间。

### 5.3 血型性格（日本/韩国特有）

A/B/O/AB 四型性格论。**科学上无效，但社会渗透率极高**（日本人对血型的重视程度类似中国人对生肖）。
App 化程度极高（纯查表），常作为星座 App 的附加模块。

## 六、总排序：按「App 化可行度 × 市场热度」

这张表是给「要做产品的人」看的，不是给「要算命的人」看的。

| 方法 | 市场热度 | App 化难度 | 技术壁垒 | 竞争强度 | 综合推荐 |
|---|---|---|---|---|---|
| **八字** | ★★★★★ 中国 60% | 低（确定性算法） | **中**（节气/起运精度是门槛） | 中 | **★★★★★** |
| **西洋占星** | ★★★★★ 美国 30% / 中国 44.8% | 低（Swiss Ephemeris） | 低（开源成熟） | **极高** | ★★★ |
| **塔罗** | ★★★★ 中国 38.9% | **极低**（随机数+预制文案） | **无** | **极高（最饱和）** | ★★ |
| **紫微斗数** | ★★★ 台港极高 | 中（流派选择） | 中 | 中低 | **★★★★** |
| **择日/黄历** | ★★★★ 刚需 | 极低（查表） | 低 | 高 | ★★★★ |
| **相术（手相/面相）** | ★★★★ 短视频热 | 低（CV 已成熟） | 低 | 高 | ★★★（合规风险高） |
| **数字命理** | ★★ | 极低（算术） | 无 | 中 | ★★ |
| **六爻** | ★★★ 中文圈 | 中（解卦靠经验） | 中 | 低 | ★★★ |
| **奇门遁甲** | ★★ | 高（极复杂） | 高 | 低 | ★★（高客单但难规模化） |
| **印度占星** | ★★★★★ 印度 | 低 | 低 | 极高（本土） | ★★（出海才值） |
| **咖啡占卜** | ★★ 新兴 | 中（CV 识别） | 中 | **低（蓝海）** | ★★★（新品类机会） |
| **卢恩符文** | ★ 小众 | 低 | 无 | 极低 | ★（无规模） |

**三个能直接用的结论**：

**① 技术壁垒最高的是八字，不是塔罗。**
塔罗零壁垒（随机数+文案），所以最饱和、最没溢价。八字的难点在节气精度、起运计算、神煞规则——这些你已经复刻到 100%，这是真护城河。

**② 紫微斗数是「投入产出比」最好的第二选择。**
台港渗透率极高、竞争远小于塔罗、排盘是确定性的、八字用户天然可转化。而且它和八字是同一批用户，做完八字顺手就能做。

**③ 咖啡占卜这类「有视觉载体的传统占卜」是蓝海。**
CV 成熟 + 没有强势玩家 + 天然适合短视频。同理还有：茶叶占卜、骰子占卜、鸟卦。

## 八、与你的项目的对应关系

你复刻问真做的是**八字**这一支。按上面的排序，这恰好是「技术壁垒最高 + 中文市场热度第一」的位置。

已完成的能力可以直接延伸：

| 现有能力 | 可延伸的方向 | 工作量 |

**最省力的增量是「择日/黄历」**——你已经有了完整的干支、节气、神煞、日课用事能力，做一个黄历页面几乎是免费的。而且它合规风险最低。
