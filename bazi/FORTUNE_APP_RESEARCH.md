| **测天机 Tianji** | 八字/紫微/奇门/西方占星 | **四体系交叉验证**：结论趋同才判定可信 | — |
| **OpenFate** | 八字/紫微/西洋/印度占星/人类图 | 免费多盘种并排 | 免费排盘 + 积分 |
| **天机阁** | 紫微 + 四柱 | 大模型角色扮演「钦天监秘传弟子」，纯 Prompt | 开源 |
| **问天AI** | 八字/紫微/七政四余/奇门/大衍筮法 | 命理师 + 大模型团队 | 内购 |

**技术架构的关键分野**（值得单独记）：

```
错误做法：把生辰丢给大模型，让它「算」八字
        → 排盘结果不稳定，同一生辰两次跑出不同四柱

正确做法：代码做排盘（确定性），AI 只做解读（编排）
        FateMaster 明确这么讲：Code produces the chart, AI orchestrates the tools
```

这和你的问真复刻项目是同一个结论：**排盘必须是确定性算法，AI 只能在解读层。**

### 2.4 已死/半死的赛道

- **AI 看脸算命**（2023 年前后）：央视曝光，上传宠物狗照片也能算出「读书运很好」，整条赛道被打掉
- **纯 H5 小测试刷屏**：微信封杀「测测你的审美类型」类裂变，2020 年后基本消失

这是最值得学的一块。

### 3.1 Co-Star（2026 年 7 月被 Midjourney 收购）
| 项 | 数据 |
|---|---|
| 上线 | 2017 年，纽约 |

**为什么 Midjourney 要买它**：AI 公司看到了「占星 × AI」的消费级产品价值。Co-Star 的核心资产不是算法，是**文案风格 + 社交裂变**。

### 3.2 The Pattern
| 项 | 数据 |
|---|---|
| 策略 | **刻意避开「星座」二字**，全用心理学语言 |
| 变现 | 免费摘要 + 「Go Deeper+」付费解锁；约 $15/月 |
| 名人 | Channing Tatum 等公开推荐 |
| 内容 | 固定报告，不易追问 |

**这是最值得抄的包装策略**：不叫「算命」，叫「人格模式分析」「关系动态」「人生时间窗口」。用户心理门槛和合规风险同时下降一个数量级。

### 3.3 Nebula（乌克兰 OBRIO，Genesis 系）

|---|---|

证明：**在 AI 泛滥的市场里，「真人写的」本身能卖溢价。**

## 八、监管风险（中国内地，必须知道）

### 8.1 现行红线
《互联网信息服务管理办法》第十五条：不得宣扬封建迷信。
微信公众号规范明确禁止三类：
1. 以算命/看相/取名/运势为由**采集用户隐私**（姓名、八字、手相、身份证、手机号）
2. 以算命为由**售卖转运消灾产品**
3. 以算命为由**提供付费咨询**

### 8.2 正在收紧：《互联网信息服务管理办法（修订草案）》
2026 年 7 月 3 日国家网信办再次公开征求意见，关键变化：

| 项 | 现行 | 修订草案 |
|---|---|---|
| 违法主体 | 仅「提供者」 | 「提供者」+「使用者」 |
| 处置措施 | 停止传输、保存记录、报告 | 增加**删除、屏蔽、断开链接、限制账号功能及营利权限、关闭账号** |
| 罚款 | 1.5 万元以下 | **分三档：5-50 万 / 50-200 万 / 200-1000 万** |
| 个人责任 | 无明确规定 | 主管人员和直接责任人：1-10 万 / 10-100 万，可**禁业** |
| 最严措施 | 停业整顿 | 可**关闭网站或应用程序** |

### 8.3 已发生的执法案例
- **2024-01**：某日历 App 设「运势测算」「热门测算」版块收费 → 约谈 + 罚款 + **应用商店下架**
- **2024-01**：某多多、某宝、某点评因审核不严传播迷信信息 → 约谈 + 警告 + 罚款
- **2025-05**：抖音/快手「国学」账号宣扬八字命理诱导付费「镇邪聚财」→ **账号关闭**
- **2026-03**：测测被曝诱导消费、达人资质代考，中央网信办开展专项整治

### 8.4 合规做法（行业内实际在用的）
1. **改称呼**：不叫「算命」，叫「传统文化研究」「命理知识学习」「性格倾向分析」
2. **改定位**：明确标注「娱乐 / 文化参考」，不做确定性承诺（「必然」「一定」是雷区）
3. **不采集**：不做用户命盘存储售卖，不做社交裂变拉新
4. **不承诺改运**：不卖「转运」商品，不说「化解」「破解」
5. **不诱导复购**：不做「再算一次就准了」的循环付费

**The Pattern 的做法是标准答案**：全用心理学语言，App Store 分类挂在 Lifestyle/健康，从头到尾不提「算命」。

## 九、值得注意的空白与机会

### 9.1 中文市场缺一个「现代化专业工具」
现状是两极：
- **平台型**（测测、灵机）：用户量大，但体验老旧、争议多、面向小白
- **工具型**（问真、陈抟、知易）：算法专业，但产品设计停留在 2010 年代，无 AI、无对话

**中间地带是空的**：专业算法 + 现代交互 + AI 解读。这正好是你复刻问真之后站的位置。

### 9.2 海外四柱（Saju/BaZi）是个增量市场
- 韩国四柱产业 37 亿美元，但产品几乎只服务韩语
- Myeongly、AskingMing 走英文路线，刚起步
- 中文市场没有同等水平的现代化产品

### 9.3 「可视化」是最新的创新点
- 韩国：AI 把命理结果画成 Webtoon 漫画
- 国内：有产品把八字做成「人生 K 线图」（吉年/凶年标注，牛市/震荡期隐喻），爆红但也引发争议
- 你的五行雷达图、能量条已经在做这件事

### 9.4 B 端 API 是被忽视的路
爱星盘靠卖星盘 API 活着。东方命理排盘 API 目前只有 FateStar 在认真做，且排盘免费。**排盘能力本身已经不是壁垒了。**

## 十、结论：五条可以直接用的判断

**① 用户要的不是「命运」，是「情绪」。**
日本数据：85% 的占卜需求是恋爱关系。测测把自己定义成「泛心理平台」而不是算命平台。谁把自己当算命做，谁就会撞监管；谁把自己当情绪服务做，谁就能规模化。

**② 最赚钱的是真人咨询，不是算法。**
AstroTalk 咨询收入占 91%，150 万付费用户，复购 25-30%。纯算法产品（如紫微斗数 App，180 万安装）月收入不到 1 万美元。

**③ 但算法是护城河，咨询是现金流。**
Co-Star 490 万 MAU 被 Midjourney 收购，买的不是占星师，是产品能力和用户。算法做到极致能卖公司。

**④ 包装决定生死。**
The Pattern 全用心理学语言，$15/月；同一套占星内容叫「算命」，在内地直接违规。同一份数据，换个说法就是两个生意。

**⑤ 排盘能力已经商品化，钱在解读层。**
FateStar 排盘 API 免费、NatalChart.AI 免费 10 次/天、开源库一堆。**只有「确定性排盘 + AI 个性化解读」的组合还有溢价空间。**
