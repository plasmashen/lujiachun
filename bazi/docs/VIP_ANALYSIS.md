## 一、等级体系

```js

L = ["黄金","黄金","钻石","钻石"]
```

| 级别 | 名称 | 计费标签 | 说明 |
|---|---|---|---|
| 0 | 非会员 | — | 基础排盘 |
| 1 | 黄金会员 | 黄金 | |
| 2 | 钻石会员 | 钻石 | |
| 3 | 钻石会员 | 钻石 | 钻石**到期后 60 天保护期**内仍按钻石处理（前端 `3==i && C(new Date(l))>=60 → i=4`） |
| 4 | 终身会员 | — | 永久 |

状态接口：

```
GET https://bzpp2.iwzbz.com/api/v1.1/user/getvipinfo?userguid=<GUID>
→ { data: { vipLevel: 0..4, expires: "YYYY-MM-DD HH:MM:SS", session, apistr } }
```

`apistr` 字段决定后续排盘走哪个后端（如 `bzapi3`）。

## 四、关键发现：会员权限的真实边界

### ① 排盘接口本身不区分会员

实测 `getbasebz8.php` 参数 `vip=0` 与 `vip=1`：

```
vip=0 字段 27   vip=1 字段 27
vip=1 独有: []
vip=0 独有: []
共有但值不同: ['runtime']
```

**27 个字段完全一致，只有 runtime 耗时不同。**
会员权限是在**前端**通过 `viplevel` 状态控制界面渲染，不是后端按 vip 参数裁剪数据。

### ② 「古籍智能推荐」是唯一真正按会员分层的内容

前端 `noVipContent` 字段 = 非会员看到的书简介。会员可看到**按命盘匹配的条目**。
9 部书里：
- 《穷通宝鉴》《滴天髓》—— 非会员可看
- 其余 7 部 —— 需要黄金/钻石

### ③ 古籍全文本身不受会员限制

`www.iwzbz.com/artical/pcbook/v2/` 下 65 部古籍（2792 章、约 566 万字）
**未登录即可读全文**，与会员体系完全无关。

### ④ 会员功能本质是「参数开关」而非「独家数据」

20 项黄金+钻石权益里，除名人八字库和断事笔筛选外，其余可归类为：

| 类别 | 功能 | 本质 |
|---|---|---|
| 流派开关 | 神煞设置、地支藏干、人元司令、格局取法、命宫身宫、刑冲破害 | 让用户选择不同理论书籍的计算方式 |
| 计算增强 | 五行能量专业版、同党异党能量、系统评估旺衰/格局 | 更细的加权算法输出 |
| 时间粒度 | 流日、流时显示 | 把流年/流月细化到日、时 |
| 内容匹配 | 智能古籍推荐、合盘五行图 | 按命盘检索古籍条目 |

**没有一项是「只有会员才能拿到的原始数据」** —— 全部是算法参数化与展示层级。
