### 4.3 起运与交运

**公式**：

```
名义秒 = round(|出生时刻 - 相邻「节」| 真实秒 × 120) - 30
再按「年干阴阳 × 顺逆」四象限修正（等价于 男 -30 / 女 +30）

年 = floor(名义秒 / 31104000)    月 = floor(余 / 2592000)
日 = floor(余 / 86400)           时 = floor(余 / 3600)
分 = floor(余 / 60)              秒 = 余 % 60
```

**交运规则**：

- 交运日期 = 出生 + 起运年/月/日
- 首干 = 交运日年柱天干（立春为界）
- 次干 = 首干合化干（甲↔己、乙↔庚、丙↔辛、丁↔壬、戊↔癸）
- 节气 = 交运日前最近「节」
- 输出：`逢X、Y年 立秋后19天 交大运`

**实测**：1990-05-15 10:30 男 → `7岁3月11天8时36分8秒`，与 API `[7,3,11,8,36,8]` 一致。

## 六、起运秒位：为什么卡在 49.39%

### 6.1 现状

| 位 | 准确率 |
|---|---|
| 年 | 100.0% |
| 月 | 99.2% |
| 日 | 98.6% |
| 时 | 97.9% |
| 分 | 93.3% |
| **秒** | **50.5%** |
| **六位全对** | **49.39%（3779/7651）** |

模型：`δ = a + b·x`（每格独立斜率），覆盖 7651/7651，缺 0 格。

### 6.2 根因

δ 表精度不足。`δ = 问真内部节气时刻 - 标准历算节气时刻`，每节气 0-30 秒跳动。

**误差分布**：中位 +1 名义秒、P95 60 名义秒、标准差 1.53s。

**已排除的可能性**（全部实测证伪，勿重试）：

```
round / ceil / floor / floor(x+1.5) / 常数偏移 / 性别残差
组中位法        15.20%
组内斜率法       0.03%
```

### 6.3 δ 模型

采用 `δ = a + b·x`（x = 距节天数），每 `(年, 节气)` 独立拟合，单格残差 std 约 4.2 名义秒。

**补采历程**：

| 批次 | 条数 | 说明 | 效果 |
|---|---|---|---|
| dense2 | 28,000 | 男 ±15 天 | 43.14% |
| dense3 | 30,680 | 全量补齐 | 45.50% |
| dense4 | 61,360 | 加女性样本 | **43.64%（下降）** |
| dense5 | 32,582 | 男 ±20 天 | **48.58%** |
| dense7 | 4,104 | 244 真缺口格 | **49.39%** |
| 合计 | ~15 万条 | 零失败 | |

### 6.4 两个关键教训

**① 女性样本必须排除。** 分层实验：男 ±15天 45.55%、男节后 45.50%、女节前 **37.25%**、混合 43.42%。女性节前样本与男性节后方向相反，混入后互相抵消。

**② 补采计划必须与拟合使用同一统计口径。** dense6 采了 23,479 条但只涨 0.05%，因为 `plan_fill4` 只统计缓存 7651 条、忽略 91,262 条密集样本，补在了已饱和的格上。

### 6.5 天花板

| 口径 | 准确率 |
|---|---|
| 当前 | 49.39% |
| 样本内拟合上限 | 58.02% |
| **人工天花板**（raw + 真 dreq） | **97.57%** |

差距全部来自 δ 表精度，不是舍入或模型形式。δ 表取决于问真内部节气时刻，每节气 0-30 秒跳动且年际不连续（相邻差 3.19 秒），继续采样收益极小。

**结论：49.39% 是当前实际终点。**

## 九、逆向经验

### 9.1 黑盒拟合必须全量二次校验

小样本上「零冲突」的规则常在扩样后失效。本轮 10 种神煞在 877 条上成立、2557 条上崩溃。

**验证时要区分「精确解」与「退化解」**：空映射（该柱从不标注）是假突破。

### 9.2 找对口径比多采样重要

dense6 的 23,479 条样本无效，根因是统计口径错误（只统计缓存、忽略密集样本）。补采前必须先确认「计划」与「拟合」用的是同一套归类逻辑。

### 9.3 前端包是最好的规格说明

问真的打包 JS 里有：六家司令表原文、藏干默认表、纳音表、格局取法规则文本、设置项编码格式。这些比猜或查书都准。

### 9.4 参数化 ≠ 数据壁垒

会员功能的本质多是「参数开关」（流派选择、显示层级），不是独家数据。所以能自行实现。
